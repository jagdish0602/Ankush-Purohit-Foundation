INSANIYAT FOUNDATION - NGO WEBSITE DEMO
=========================================
Files:
- index.html : main webpage
- style.css  : responsive styling
- script.js  : mobile menu, sticky header, counters and demo form

Open index.html directly in a browser. No build step is required.

Note:
This is a fresh HTML/CSS/JS frontend inspired by the humanitarian NGO structure and visual direction of the supplied reference package. Replace contact details, impact numbers and program copy with your verified organization information before publishing.
